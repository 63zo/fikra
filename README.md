# منصة فكرة (Fikra) — نظام إدارة الابتكار والأفكار المؤسسية
### جامعة بيشة | University of Bisha

**فكرة (Fikra)** هو نظام رقمي متكامل مصمم لمنسوبي جامعة بيشة (أعضاء هيئة التدريس، الموظفين، والباحثين) لتوليد الأفكار التطويرية، تحكيمها، وقياس أثرها الاستراتيجي، مع دمج تقنيات الذكاء الاصطناعي لاكتشاف التشابه في الوقت الفعلي والتصنيف الذاتي.

---

## 🌟 أبرز مميزات النظام (Key Features)

1. **الهوية البصرية وتجربة المستخدم**:
   - ألوان وتصميم مستوحى من البوابة الرسمية ونظام الدخول الموحد لجامعة بيشة (`#14573A` الأخضر الملكي، `#C5A059` الذهبي).
   - ثنائي اللغة بالكامل (**العربية كافتراضي RTL** / **الإنجليزية LTR**) مع التبديل الفوري بنقرة واحدة.
   - دعم الوضع الداكن والفاتح (Dark / Light Theme).
   - متجاوب بالكامل 100% مع أجهزة الجوال والأجهزة اللوحية والحواسيب المكتبية.

2. **الدخول الموحد والتسجيل الآمن**:
   - واجهة تسجيل دخول بتصميم SSO الخاص بجامعة بيشة.
   - شريط تجربة سريع بنقرة واحدة للتبديل بين الأدوار: **موظف (Employee)**، **عضو لجنة تحكيم (Committee)**، و**مدير نظام (Admin)**.
   - صفحة تسجيل موظف جديد بقوائم ديناميكية للكليات والإدارات والمسميات الوظيفية.
   - مقياس حي لقوة كلمة المرور (8 خانات، أحرف كبيرة وصغيرة، أرقام، ورموز خاصة).
   - استعادة كلمة المرور برمز تحقق عبر البريد الإلكتروني وتغيير كلمة المرور من الملف الشخصي.

3. **رادار الذكاء الاصطناعي لاكتشاف التشابه في الوقت الفعلي (AI Duplicate Radar)**:
   - يبدأ البحث الذكي فور كتابة **3 كلمات أو أكثر** في عنوان أو تفاصيل الفكرة.
   - يحلل التشابه الدلالي ويظهر تنبيهاً فورياً بنسبة التطابق مع زر لمقارنة الفكرة بالأفكار السابقة لتجنب التكرار.
   - تصنيف آلي للأفكار واقتراح وسوم ذكية (#التحول_الرقمي، #الاستدامة، إلخ) ومؤشر أثر تقديري.

4. **الإدخال الصوتي (Speech-to-Text)**:
   - دعم التحدث بالصوت باللغتين العربية والإنجليزية وتحويله فورياً لنص مكتوب مع أمواج صوتية متحركة.

5. **بنك الأفكار والتفاعل المجتمعي**:
   - عرض الأفكار مع خيارات التصفية (حسب الكلية/الإدارة، الحالة، المجال) والترتيب.
   - نظام تصويت تفاعلي مع منع تكرار التصويت.
   - مناقشات وتعليقات تفاعلية على كل فكرة.
   - طباعة وثيقة الفكرة وتصديرها بصيغة PDF.

6. **بوابة لجان التحكيم والتقييم (Committee Review Portal)**:
   - مصفوفة معايير مؤسسية (المواءمة الاستراتيجية، الابتكار، قابلية التنفيذ، الأثر والعائد).
   - قرارات رسمية (اعتماد / طلب تعديل / رفض) مع تدوين الملاحظات الرسمية للموظف.

7. **لوحة التحليلات والمؤشرات (Analytics & Chart.js)**:
   - رسوم بيانية تفاعلية لتوزيع الأفكار حسب الكليات، نسب القبول والرفض، ومسار التقديم الزمني.
   - مؤشرات أداء رئيسية (KPIs) وتصدير البيانات كملف CSV.

8. **إدارة النظام والقوائم المنسدلة (System Admin)**:
   - إدارة كاملة لإضافة وحذف وتعديل قيم القوائم المنسدلة (الكليات، المسميات الوظيفية، مجالات الأفكار).
   - إدارة صلاحيات المستخدمين.

9. **لوحة الشرف ونظام النقاط (Gamification)**:
   - ترتيب أفضل المبتكرين والكليات النشطة وحساب النقاط والأوسمة.
